# ML / DL Practice & LeetCode

A continuously growing collection of Python implementations, coding exercises, and small experiments focused on machine learning, deep learning, and the mathematical foundations behind modern AI systems.

The goal of this repository is to strengthen practical understanding by implementing concepts from scratch, solving focused ML/DL challenges, and revisiting core topics regularly.

## Topics Covered

- Machine Learning
- Deep Learning
- Computer Vision
- Natural Language Processing
- Transformers & LLMs
- Reinforcement Learning
- Recommender Systems
- Information Retrieval
- Multimodal AI
- ML Engineering
- Probability
- Statistics
- Linear Algebra
- Unsupervised Learning
