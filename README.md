## Why This Repository Exists

This repository is part of my ongoing machine learning and deep learning learning workflow.

Instead of focusing only on high-level frameworks, I use these exercises to better understand:

- how ML algorithms work internally,
- how mathematical concepts translate into code,
- how common deep-learning operations are implemented,
- how to reason about tensors, matrices, probabilities, and data flow,
- how to write clean and readable Python solutions,
- how to understand model behaviour beyond simply calling library APIs.

The main focus is on practical implementation and strengthening the foundations behind modern machine learning systems.
